KOTE 뉴스 헤드라인 감정 라벨링 플랫폼

화면 흐름 와이어프레임

32만 건 뉴스 헤드라인에서 층화 샘플링한 1,000건을 작업자가 KOTE 44개 감정으로 멀티라벨 라벨링하는 웹앱입니다. 화면은 서버 없이 정적 페이지로 배포되고(Vercel), 라벨은 브라우저에서 클라우드 데이터베이스(Firestore)에 직접 기록됩니다. 로그인·비밀번호 없이 이름 선택 = 브라우저 잠금 방식으로 본인 확인을 대신합니다.

접속·종료 예외 로직

로그인 없이 운영하는 대신, 이름을 선택한 브라우저가 그 이름을 '잠금'으로 독점합니다. 잠금 소유자 확인과 데이터 접근 제한은 화면이 아니라 데이터베이스 보안 규칙이 서버 측에서 강제하므로 우회할 수 없습니다.

접속할 때 — 이어하기와 충돌 처리

같은 브라우저로 재접속자동 이어하기

선택한 이름이 브라우저에 저장되어 있어 선택 화면 없이 바로 내 큐로. 저장·스킵 상태가 그대로 복원되고 첫 미완료 건으로 자동 이동합니다.

전용 링크로 접속 (?annotator=이름)자동 선택

작업자별 공유 링크를 열면 이름 선택 단계를 건너뜁니다. 메신저로 링크만 전달하면 작업자가 이름을 잘못 고를 여지가 없습니다.

다른 브라우저·기기에서 같은 이름으로 접속차단

"이미 다른 브라우저에서 사용 중입니다" 안내 후 선택 화면으로 복귀. 같은 이름의 판정이 두 곳에서 동시에 섞여 기록되는 것을 막기 위한 규칙입니다.

다른 작업자의 데이터에 접근 시도차단

잠금 소유 브라우저가 아니면 해당 작업자의 배정·라벨 읽기와 쓰기가 데이터베이스 차원에서 거부됩니다. 화면 조작이나 주소 변경으로 우회할 수 없습니다.

종료·이탈할 때 — 잠금과 미저장 편집의 행방

'세션 종료' 버튼으로 정상 종료잠금 해제

확인 후 이름 잠금을 해제하고 이 브라우저의 선택 기억도 지웁니다. 이후 다른 브라우저·기기에서 그 이름으로 이어서 작업할 수 있습니다.

창·탭을 그냥 닫음잠금 유지

별도 처리가 없습니다. 같은 브라우저로 다시 열면 그대로 이어하기 — 일상적 중단은 이 방식으로 충분합니다. 단, 그 사이 다른 기기에서는 이 이름을 쓸 수 없습니다.

'변경' 버튼으로 이름 전환잠금 유지

잠금은 그대로 두고 작업자 선택 화면으로 돌아갑니다. 이 브라우저가 소유한 다른 이름을 오갈 때 사용하고, 이름을 완전히 놓아줄 때는 '세션 종료'를 씁니다.

세션 종료 실패 (내 소유가 아닌 잠금)관리자 해제

다른 브라우저가 만든 잠금은 앱 안에서 해제할 수 없습니다. 안내 후 이 브라우저의 선택 기억만 지우고 선택 화면으로 복귀 — 잠금 자체는 관리자에게 해제를 요청합니다.

브라우저 데이터 삭제·기기 교체관리자 해제

새 브라우저로 취급되어 본인 이름의 잠금에 스스로 막힙니다. 관리자가 해제 스크립트(unlock_annotator)로 잠금을 풀어준 뒤 재접속하면 작업 기록은 그대로 이어집니다.

라벨을 골랐지만 저장 전에 이탈주의

미저장 편집은 화면 이동에는 유실 없이 유지되고 '변경 사항' 모달로 추적되지만, 브라우저를 닫으면 사라집니다. 저장된 라벨은 건별 즉시 기록이라 안전 — 종료 전 '변경 사항 0건'만 확인하면 됩니다.

데이터 설계 요점

서버 없는 구조

정적 페이지(Vercel) + 클라우드 DB(Firestore) 직결. 별도 서버 운영 없이 배포·유지되고, 저장은 건별로 즉시 클라우드에 기록.

규칙 검증을 서버 측에서 강제

'없음' 단독 선택, 스킵 사유 필수, 44개 라벨 정합성, 잠금 소유자 확인을 데이터베이스 보안 규칙이 재검사 — 화면 우회 저장 불가.

작업자별 전체 큐 배정

초기 Sample 한 명으로 시작하고, 새 작업자 추가 시 현재 1,000건 전체 큐를 자동 생성. 필요 시 IAA용 중복 라벨링으로 확장.

제시 순서 작업자별 셔플

작업자마다 큐 순서를 분리해 같은 기사라도 서로 다른 작업 시점에 보도록 설계.

건별 즉시 저장 (upsert)

매 건 저장 확인 후 이동. 수정 시 덮어쓰기라 작업자당 최종 판정이 정확히 1개. 작업자·시각 기록.

모델 개입 차단 (기본값)

모델 추천·예측순 정렬은 설정으로만 활성화. 사람의 독립 판정을 확보해 평가용 gold set 오염 방지.
